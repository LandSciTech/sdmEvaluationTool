The goal of sdmEvalToolUI is to implement Shiny functionality according to
the SDM Evaluation Tool requirements for uploading materials.

## Installation

You can install the development version of sdmEvalToolUI from [GitHub](https://github.com/) with:

``` r
remotes::install_github("LandSciTech/sdmEvaluationTool/sdmEvalToolUp")
```

## Example

This is a basic example which shows you how to solve a common problem:

``` r
library(sdmEvalToolUp)
## basic example code
```
