
# sdmEvalToolCore

<!-- badges: start -->
<!-- badges: end -->

The goal of sdmEvalToolCore is to implement the data model and non-interactive
functionality for sdmEvalToolUI according to the SDM Evaluation Tool requirements.

## Installation

You can install the development version of sdmEvalToolCore from [GitHub](https://github.com/) with:

``` r
remotes::install_github("LandSciTech/sdmEvaluationTool/sdmEvalToolCore")
```

## Example

This is a basic example which shows you how to solve a common problem:

``` r
library(sdmEvalToolCore)
## basic example code
```
