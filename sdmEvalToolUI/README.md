The goal of sdmEvalToolUI is to implement Shiny functionality according
to the SDM Evaluation Tool requirements for evaluating materials.

## Installation

You can install the development version of sdmEvalToolUI from
[GitHub](https://github.com/) with:

``` r
remotes::install_github("LandSciTech/sdmEvaluationTool/sdmEvalToolUI")
```

The tool can be launched with `sdm_tool()`.

``` r
library(sdmEvalToolUI)
sdm_tool()
```
